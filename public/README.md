# Carpeta de Recursos Públicos (Public Assets)

Coloca aquí los archivos de imagen de tu empresa para que la aplicación pueda acceder a ellos directamente.

### Archivos sugeridos:
1. `logo.svg` o `logo.png` - Logotipo principal (símbolo + nombre) para la pantalla de inicio de sesión.
2. `isotipo.svg` o `isotipo.png` - Símbolo simplificado (solo la ampolleta o icono) para el menú lateral.
3. `favicon.ico` - Icono para la pestaña del navegador.

*Nota: Una vez que agregues tus archivos aquí con estos nombres exactos, la aplicación se actualizará automáticamente si ya hemos hecho los cambios en el código.*
